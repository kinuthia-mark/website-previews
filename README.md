# Website previews

Free preview websites I build for small businesses in Nairobi before pitching them, so the owner sees their site working instead of hearing about it.

Each preview uses only the business's public Google Maps details (rating, review count, opening hours, location, phone) and labels the menu or services as a sample until the owner sends the real ones. Every page has an order/booking form that opens WhatsApp to the business, a live "open now" line in Nairobi time, and an M-Pesa payment demo.

Pages are marked `noindex` and search engines are blocked: they're previews for one owner each, not the businesses' official sites.

Built by Mark Kinuthia, web developer, Nairobi.
